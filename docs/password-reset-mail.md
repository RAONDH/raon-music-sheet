# 비밀번호 찾기 메일 설정

로그인 화면의 **✉️ 비밀번호 재설정 메일 받기**는 가입한 이메일로 재설정 링크(30분, 한 번만)를 보냅니다.
메일을 보내려면 Vercel 프로젝트 **Settings → Environment Variables**에 아래 값을 넣고 다시 배포해야 합니다.
값을 넣기 전까지는 "비밀번호 찾기 메일이 아직 준비되지 않았습니다. 팀장이나 관리자에게 임시 비밀번호를 요청해 주세요"라고 안내합니다.

> 비밀번호·API 키는 운영자가 직접 넣습니다. 채팅이나 코드에 적지 마세요.

## 방법 1. Gmail로 보내기 (가장 쉬움, 하루 약 500통)

1. 보내는 데 쓸 Gmail 계정에 **2단계 인증**을 켭니다.
2. Google 계정 → 보안 → **앱 비밀번호**에서 새 앱 비밀번호(16자리)를 만듭니다.
3. Vercel 환경 변수:

| 이름 | 값 |
|---|---|
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | 보내는 Gmail 주소 |
| `SMTP_PASS` | 2번에서 만든 앱 비밀번호 (띄어쓰기 없이) |

받는 사람에게는 이 Gmail 주소에서 메일이 갑니다.

## 방법 2. Resend로 보내기 (무료 한 달 3,000통, 내 도메인 주소로 보냄)

1. resend.com에 가입하고, 보낼 도메인을 등록해 DNS 인증을 마칩니다.
2. API 키를 만듭니다.
3. Vercel 환경 변수:

| 이름 | 값 |
|---|---|
| `SMTP_HOST` | `smtp.resend.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | `resend` |
| `SMTP_PASS` | Resend API 키 |
| `MAIL_FROM` | 인증한 도메인의 주소 (예: `noreply@내도메인`) |

## 그 밖의 값 (선택)

| 이름 | 설명 |
|---|---|
| `MAIL_FROM` | 보내는 주소. 없으면 `SMTP_USER`로 보냅니다. `RAON <noreply@…>` 형식도 됩니다. |
| `APP_URL` | 메일 속 링크의 앱 주소. 없으면 `https://raon-music-sheet.vercel.app`. 주소를 바꾸면 넣습니다. |

## 안전장치

- 링크 토큰은 DB에 원문이 아니라 해시로만 저장하고, 30분이 지나거나 한 번 쓰면 못 씁니다.
- 비밀번호를 바꾸면 다른 기기에 남은 로그인은 모두 끊깁니다.
- 메일 폭탄 방지: 한 기기 15분에 5번, 한 이메일 1시간에 3번, 사이트 전체 1시간에 60번까지.
- 없는 이메일·사용 중지 계정에도 같은 안내를 보여 주고, 메일은 보내지 않습니다.
- 링크 주소는 요청의 Host 헤더가 아니라 `APP_URL`로 만듭니다.
